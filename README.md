# Interpretable Benchmark Explorer

A searchable explorer of frontier and open model scores. The numbers stay visible. Every score carries the context needed to interpret it: what the benchmark tests, how hard it is, whether the run is comparable, and where the number came from.

The specification is [Interpretable_Benchmark_Explorer_Design_Doc.md](./Interpretable_Benchmark_Explorer_Design_Doc.md).

Status: design. No application code yet.
